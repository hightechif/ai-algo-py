# The AI Algorithms Curriculum

This list represents a structured learning path for mastering ML and AI algorithms.
It outlines the progression from foundational concepts to advanced deep learning and reinforcement learning.

## Module 1: The Foundations & Distance (Supervised)
1. Linear Regression
2. Logistic Regression
3. K-Nearest Neighbors (KNN)
4. Naive Bayes
5. Support Vector Machine (SVM)

## Module 2: Trees & Ensembles (Supervised)
6. Decision Tree
7. Random Forest
8. AdaBoost
9. Gradient Boosting
10. XGBoost
11. Isolation Forest

## Module 3: Finding Structure (Unsupervised)
12. Principal Component Analysis (PCA)
13. t-SNE (t-Distributed Stochastic Neighbor Embedding)
14. k-Means Clustering
15. k-Means++
16. Hierarchical Clustering
17. DBSCAN (Density-Based Spatial Clustering of Applications with Noise)
18. Gaussian Mixture Models (GMM)

## Module 4: Deep Learning Foundations (Neural Networks)
19. Artificial Neural Network (ANN)
20. Autoencoders
21. Convolutional Neural Network (CNN)
22. Recurrent Neural Network (RNN)
23. Long Short-Term Memory (LSTM)
24. Generative Adversarial Networks (GANs)
25. Transformer

## Module 5: Learning via Reward (Reinforcement Learning)
26. Markov Decision Process (MDP)
27. Q-Learning
28. SARSA (State-Action-Reward-State-Action)
29. Deep Q-Network (DQN)
30. Policy Gradient
31. Actor-Critic

## Module 6: Evolutionary Computing
32. Genetic Algorithm

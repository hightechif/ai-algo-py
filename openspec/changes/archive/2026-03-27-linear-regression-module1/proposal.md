# Proposal: Linear Regression Module (Module 1)

## What
Implement the foundational Learning Module 1: Linear Regression within the `ai-algo-py` repository. This includes delivering both a from-scratch mathematical implementation (using NumPy) and an identical framework implementation (using `scikit-learn`), bound together by a Jupyter notebook tutorial.

## Why
Linear regression sits at the absolute foundation of all supervised machine learning and deep learning algorithms. By implementing it purely via underlying mathematics (calculating MS Error and tracking Gradients for optimization), we solidify our understanding of how an AI "learns" before moving on to complex neural networks or ensembles. Utilizing the California Housing dataset guarantees the data represents real-world numbers rather than perfect, fabricated synthetic scenarios.
